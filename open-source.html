Open-source software (English)

Last updated: October 3, 2026

This software uses code of FFmpeg licensed under the LGPLv2.1 and its source can be downloaded here.

Collaj’s video export uses FFmpeg, which does not belong to Collaj. This page gives the complete source code of the FFmpeg build shipped in the app, as its licence requires. The licences of every component, and of the fonts, are also listed in the app: Settings › About › Licenses.

What the app contains

Collaj ships FFmpeg 8.1.2 as seven dynamic frameworks, loaded at run time and replaceable: libavutil, libswresample, libswscale, libavcodec, libavformat, libavfilter (FFmpeg, GNU LGPL 2.1 or later) and fftools (FFmpeg’s command-line tool as a library, GNU LGPL 3.0 or later). FFmpeg was configured without --enable-gpl and without --enable-nonfree. Built in: zimg 3.0.6 (WTFPL), OpenH264 2.6.0 (BSD-2-Clause), dav1d 1.5.4 (BSD-2-Clause).

Download the source code

collaj-ffmpeg-8.1.2-sources.tar.gz (75.5 MB)
SHA-256 fb1906ac33feaeee4dff8cfaee1d073520cee4ca18523e3aad34fc4c9a4e4a54

It contains the upstream release archives byte for byte (FFmpeg, zimg, OpenH264, dav1d, and the FFmpegKitNext fftools adaptation), no patch, the exact configure line of each architecture, the toolchain versions, the build script that produced the frameworks from them on macOS with Xcode, and the licence texts. Its SOURCES.md explains how to rebuild the libraries and replace them in the app.

Earlier versions

Collaj 1.0 to 1.1.1 used a prebuilt FFmpeg 6.0 from the ffmpeg_kit_flutter_new_gpl package, built with --enable-gpl by its publisher from the FFmpegKit 6.0 build scripts. Its sources are those of FFmpeg n6.0 and of the libraries listed on FFmpegKit’s source page. Collaj 1.1.2 and later use the build above, under the LGPL only.

Availability

Each source bundle stays on this page for at least three years after the last distribution of the app version that contains it. Questions: collaj.app@proton.me (Arnaud Desné EI).

Dernière mise à jour : 3 octobre 2026

Ce logiciel utilise du code de FFmpeg sous licence LGPLv2.1, dont la source peut être téléchargée ici.

L’export vidéo de Collaj utilise FFmpeg, qui n’appartient pas à Collaj. Cette page donne le code source complet de la version de FFmpeg livrée dans l’app, comme sa licence l’exige. Les licences de chaque composant, et des polices, sont aussi listées dans l’app : Réglages › À propos › Licences.

Ce que contient l’app

Collaj livre FFmpeg 8.1.2 sous forme de sept frameworks dynamiques, chargés au lancement et remplaçables : libavutil, libswresample, libswscale, libavcodec, libavformat, libavfilter (FFmpeg, GNU LGPL 2.1 ou ultérieure) et fftools (l’outil en ligne de commande de FFmpeg sous forme de bibliothèque, GNU LGPL 3.0 ou ultérieure). FFmpeg a été configuré sans --enable-gpl ni --enable-nonfree. Compilés dedans : zimg 3.0.6 (WTFPL), OpenH264 2.6.0 (BSD-2-Clause), dav1d 1.5.4 (BSD-2-Clause).
